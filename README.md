- Volta Ao Quênia

Um site desenvolvido com HTML, CSS e Bootstrap com o objetivo de apresentar informações sobre o Quênia de forma visual, organizada e responsiva.

- Sobre o Projeto

O Quênia Explorer é um site informativo que explora aspectos culturais, turísticos e sociais do Quênia, trazendo conteúdo dividido em páginas específicas para facilitar a navegação do usuário.

O projeto foi desenvolvido com foco em:

Aprendizado de Bootstrap
Organização de páginas web
Estruturação de layout responsivo
Aplicação de estilos personalizados com CSS
- Estrutura do Site

O site é composto pelas seguintes páginas:

Home (index.html)
Apresentação geral do país, com destaque para turismo, cultura e inovação.
Turismo (turismo.html)
Informações sobre pontos turísticos, safáris e paisagens naturais.
Culinária (culinaria.html)
Pratos típicos e curiosidades sobre a gastronomia local.
Notícias (noticias.html)
Atualizações e informações relevantes sobre o país.
Curiosidades (curiosidades.html)
Fatos interessantes sobre cultura, sociedade e inovação.
